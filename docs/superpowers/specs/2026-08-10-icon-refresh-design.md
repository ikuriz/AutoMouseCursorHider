# 应用图标更新设计

## 目标

将新的极简鼠标海报图作为 AutoMouseCursorHider 的应用图标和系统托盘图标，保留原图的完整留白构图。

## 图标策略

- 第一阶段保留整张方形海报，不裁剪鼠标主体。
- 从 PNG 生成包含 16、24、32、48、64、128、256 像素的多尺寸 ICO。
- EXE 文件资源和系统托盘均使用同一份 ICO，保证视觉一致。
- 不修改原始图片内容，不添加文字或额外装饰。
- 如果 16×16 或 24×24 托盘尺寸下主体辨识度不足，再进行第二阶段主体裁剪；本次不预先裁剪。

## 文件与构建

- 保存原始图片到 `native/assets/app-source.png`。
- 生成图标保存到 `native/assets/AutoMouseCursorHider.ico`。
- 保留可重复执行的图标生成脚本，便于后续替换源图。
- `app.rc` 继续通过 `IDI_APP` 引用 ICO。
- `TrayController` 继续从 `IDI_APP` 加载托盘图标。

## 兼容与验证

- 不增加运行时依赖，不改变鼠标隐藏、托盘菜单或设置逻辑。
- 编译 Release x64 版本并运行现有 CursorState、ConfigStore 测试。
- 检查 EXE 和托盘是否都加载新图标。
- 更新体验版 EXE；发布版本号在实现完成后按补丁版本递增。
