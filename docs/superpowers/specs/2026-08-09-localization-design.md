# AutoMouseCursorHider 多语言适配设计规格

## 目标

为原生 Win32 v2.0 增加英文和简体中文界面，默认跟随 Windows 用户界面语言，并允许用户在设置窗口中手动切换。

## 语言模式

INI 保存语言模式：

```ini
[Language]
Mode=auto
```

支持：

- `auto`：启动时读取 Windows 用户界面语言；中文系统使用 `zh-CN`，其他系统使用 `en-US`。
- `en-US`：强制英文。
- `zh-CN`：强制简体中文。

默认使用 `auto`，不把一次自动检测结果永久写死，保证系统语言变化后仍能跟随。

## 实现结构

- 使用稳定的字符串 ID 作为界面文案索引。
- 在 EXE 内嵌英文和简体中文文字表，不新增运行时文件或依赖。
- `Localization` 负责解析模式、检测系统语言、返回当前语言文本。
- 托盘菜单和设置窗口都通过 `Localization` 获取文字，不再硬编码界面文案。
- 手动切换语言后立即刷新设置窗口；关闭设置窗口后更新托盘菜单。

## 覆盖文案

包括标题、Settings/设置、Pause/暂停、Resume/恢复、Exit/退出、Delay/延迟时间、seconds/秒、Enable auto-hide/启用自动隐藏、Start with Windows/开机时启动、说明文字、OK/确定、Cancel/取消、错误提示和保存失败提示。

## 验收标准

- 中文 Windows 首次运行显示简体中文；非中文 Windows 首次运行显示英文。
- 设置窗口可以选择系统默认、简体中文或 English。
- 切换语言后设置窗口文字立即更新，托盘菜单在关闭设置后更新。
- 重启程序后语言模式保持；`auto` 模式仍能跟随系统语言变化。
- 现有隐藏、恢复、暂停、退出、延迟和开机自启功能不受影响。
- EXE 仍为单文件，不增加外部语言文件或运行时依赖。
