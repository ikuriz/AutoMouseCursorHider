# AutoMouseCursorHider 原生 Win32 v2.0 设计规格

## 目标

在不修改现有 .NET `v1.0.0` 的前提下，新增纯 Win32 C++ 版本，提供单个绿色 EXE：无需 .NET 或 VC++ Runtime，支持系统级鼠标隐藏与恢复。

## 分阶段范围

### 阶段一：隐藏/恢复核心

- 使用 Unicode Win32 GUI 入口和消息循环。
- 在消息线程安装 `WH_MOUSE_LL` 全局低级鼠标钩子。
- 用单调时钟和 Win32 定时器判断静止时长。
- 使用 `SetSystemCursor` 替换 13 个交互式系统光标。
- 鼠标活动时把恢复请求投递到消息线程，避免在钩子回调中同步执行重操作。
- 使用 `SystemParametersInfoW(SPI_SETCURSORS)` 恢复系统光标，并触发当前光标重绘。
- 启动、暂停、正常退出和恢复失败重试路径都必须清理光标状态。

验收标准：在资源管理器、桌面和其他应用中，静止达到阈值后隐藏，任意鼠标活动后立即恢复；异常恢复失败不崩溃、不阻断钩子链。

### 阶段二：托盘和单实例

- 使用 `Shell_NotifyIconW` 创建托盘图标。
- 右键菜单提供设置入口、暂停/恢复和退出。
- 使用命名互斥体限制单实例。
- 退出信号通过窗口消息安全地回到消息线程。

验收标准：无主窗口常驻桌面；托盘图标可打开菜单；重复启动不会创建第二个实例；退出后光标恢复。

### 阶段三：设置和配置

- 使用原生 Win32 对话框控件。
- 使用数字输入框与上下调节按钮，支持小数秒。
- 配置写入当前用户 `%LOCALAPPDATA%\\AutoMouseCursorHider\\settings.ini`。
- 配置损坏或越界时回退到安全默认值。
- 通过 `HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run` 提供当前用户开机自启。

验收标准：设置保存后重启仍生效；输入非法值不会崩溃或写入无效配置；开机自启只影响当前用户。

## 构建与发布

- 使用 MSVC/Windows SDK 编译 Windows x64 GUI 程序。
- 使用静态运行库 `/MT`，不依赖 VC++ Runtime。
- 启用高 DPI 感知 manifest。
- 使用 Release、去除调试符号和不必要资源；不使用 UPX。
- 发布包默认只包含一个 EXE；README 同时保留构建说明和安全恢复说明。

## 安全与恢复

- 不请求管理员权限、不联网、不收集数据。
- `SetSystemCursor` 的会话级影响必须在正常退出和暂停时恢复。
- 启动时先恢复系统光标，处理上次异常终止遗留状态。
- 所有 Win32 API 返回值都检查；钩子回调始终调用 `CallNextHookEx`。

## 测试策略

- 核心状态机使用单元测试覆盖阈值、移动恢复、暂停/恢复和恢复重试。
- 原生程序使用桌面冒烟测试覆盖隐藏、移动恢复、托盘菜单、重复启动、正常退出和强制终止后的下次启动恢复。
- 使用 `dumpbin /dependents` 或同等工具确认最终 EXE 不依赖 VC++ Runtime；使用 Process Monitor/运行环境验证不依赖 .NET。
- 保留 .NET `v1.0.0` 作为回退版本，原生 v2.0 未通过验收前不替换默认发布物。
