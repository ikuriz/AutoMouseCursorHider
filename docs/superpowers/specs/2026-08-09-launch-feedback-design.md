# 启动反馈与静默自启设计

## 目标

让用户手动双击 EXE 时得到明确反馈，同时保持 Windows 开机自启的静默体验。

## 用户行为

| 启动方式 | 行为 |
|---|---|
| 手动双击 EXE | 启动程序并打开设置窗口 |
| Windows 开机自启 | 启动程序但不打开设置窗口，只在系统托盘运行 |
| 程序已运行时再次双击 EXE | 不创建第二个实例，通知已有实例打开并聚焦设置窗口 |
| 托盘打开 Settings | 保持现有行为，打开并聚焦设置窗口 |

手动启动打开设置窗口只提供启动反馈，不改变“启用自动隐藏”、延迟、开机启动或语言设置。

## 实现方案

### 启动参数

- 普通双击不带参数，视为交互式启动。
- 开机启动快捷方式使用 `--startup` 参数，视为静默启动。
- 参数解析只影响是否打开设置窗口，不影响自动隐藏功能初始化。

### 单实例通信

继续使用现有单实例锁。发现已有实例时，第二个进程向已有实例发送自定义窗口消息，然后退出。

消息内容表示“显示设置窗口”，由已有实例在消息循环中：

1. 显示设置窗口；
2. 将设置窗口置于前台；
3. 不创建第二个托盘图标或鼠标监控钩子。

### 开机启动

开机启动注册项保存当前 EXE 路径并追加 `--startup`。关闭开机启动时删除该注册项。现有设置窗口中的“Start with Windows”选项继续控制这一功能。

## 兼容与安全

- 不需要管理员权限。
- 重复启动不会改变当前配置或暂停/恢复状态。
- 设置窗口关闭后程序继续静默运行在托盘中。
- 退出路径仍然恢复系统光标。
- 未知启动参数不触发设置窗口，按静默启动处理，避免外部调用意外打扰用户。

## 验证标准

1. 手动双击时能看到设置窗口。
2. 使用 `--startup` 启动时不显示设置窗口。
3. 已运行时再次双击只打开已有设置窗口，任务管理器中仍只有一个进程和一个托盘图标。
4. 托盘 Settings、重复双击和开机自启不会破坏鼠标隐藏、暂停/恢复及退出恢复逻辑。
5. 现有 CursorState 和 ConfigStore 测试继续通过。
