# 图标主体放大与 EXE 图标刷新设计

## 目标

在保留新鼠标海报视觉风格的前提下，适当放大中间鼠标主体，并确保 EXE 图标与托盘图标同时更新。

## 方案

- 从现有源图中识别鼠标主体边界。
- 以主体为中心生成方形裁剪区域，保留少量均匀边距，不拉伸、不变形。
- 重新生成 16、24、32、48、64、128、256 像素的 ICO，所有尺寸使用相同构图比例。
- 更换 `IDI_APP` 资源 ID，强制 EXE 使用新的图标资源组，降低 Windows Shell 继续命中旧缓存的概率。
- 托盘继续从新的 `IDI_APP` 加载图标，保证 EXE 与托盘一致。

## 约束

- 不修改鼠标隐藏逻辑、托盘菜单、设置窗口或运行时依赖。
- 不新增管理员权限要求。
- 如果主体边缘在小尺寸下仍然不清晰，只报告结果，不自动进行第二次裁剪。

## 验证

- 编译 Release x64 版本。
- 运行 CursorState 和 ConfigStore 测试。
- 检查 EXE 资源和托盘图标均使用新资源。
- 更新 `native/publish/AutoMouseCursorHider.exe`。
